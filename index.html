Clique em “Processar imagem” para medir os três algoritmos.

Cada algoritmo é implementado em Rust (src/lib.rs) e exportado via wasm-bindgen. Os pixels são escritos uma única vez na memória linear do módulo Wasm (funções *_ptr + alloc/dealloc), sem cópia adicional a cada chamada — só o algoritmo em si entra no tempo medido. O tempo de cada chamada é medido do lado JavaScript com performance.now(), em N execuções consecutivas sobre a mesma entrada — mesmo protocolo usado na versão JavaScript pura, para permitir a comparação direta descrita na metodologia do TCC. Imagens grandes são redimensionadas (lado maior ≤ 1600 px) para manter a demonstração responsiva no navegador.
